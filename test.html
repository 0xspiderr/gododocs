NetCharacterComponent Class Reference

Inherits Node

Synopsis

    Base component that orchestrates other latency compensation components. Also handles dependency injection for other components. Needs to be added to a root node derived from a physics body class.

Members


sim_properties: StringName[]

        Properties of the root node that need to be used by prediction and other latency compensation components(e.g position, rotation, velocity, etc). These properties will be interpolated, reconciled and synchronized across the network.

physics_body: Node

        Must be the root physics character body that will be predicted

visual_body: Node

        Must be a node that contains all of the visual child nodes e.g Sprites/Camera/Meshes

input: NetInput

        Input, the local peer should have authority over this node, holds custom input logic based on what the devs need

prediction_component: NetPredictionComponent

        Prediction component handles client-side prediction and reconciliation

interpolation_component: NetInterpolationComponent

        Interpolation component handles local and remote peer interpolation

simulator: NetSimulator

        Simulator holds custom movement/combat/etc logic implemented by the devs

_current_input: Dictionary
