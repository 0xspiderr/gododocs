# Purpose

The purpose of this tool is to take a directory of XML files generated by the<br>
godot doctool and transform them into markdown files for documentation pages.<br>
It could be nicely automated with a shell script.<br>
	
## Usage

	git clone https://github.com/0xspiderr/gododocs/tree/main
	cd gododocs
	; generate binaries for linux/windows/macOS
	make
	; go to your godot project root dir and generate the docs from your gdscript files
	godot --doctool <path-to-xml-dir> --gdscript-docs <path-to-gdscript-files>
	; add the gododocs binary to your godot project or use it from the cloned repo
	gododocs -in <path-to-xml-dir> -out <path-to-md-dir>
